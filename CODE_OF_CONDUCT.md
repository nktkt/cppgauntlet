# Code of Conduct

CppGauntlet should be a practical, respectful place to build C++ verification tooling.

## Expected Behavior

- Be direct, specific, and constructive.
- Assume good intent, but correct technical problems clearly.
- Keep discussions focused on the work, evidence, and user impact.
- Respect different experience levels and operating environments.
- Credit contributions and avoid misrepresenting ownership.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.
- Dismissing bug reports or user problems without evidence.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or reject contributions that violate this code. Serious or repeated violations may lead to a permanent ban from project spaces.

## Reporting

If you see a conduct issue, contact the repository maintainer through GitHub. Include links, screenshots, or context when possible.
